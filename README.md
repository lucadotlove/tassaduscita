# Tassa d'Uscita — terza versione

## Test locale
Apri `index.html` con un doppio clic oppure, da terminale nella cartella:

```bash
python3 -m http.server 8080
```

Poi visita `http://localhost:8080`.

## Direzione creativa
Questa versione usa un linguaggio di destra sociale e nazionale: sovranità economica, famiglia, lavoro, sicurezza, proprietà diffusa e difesa del ceto medio. La critica alla concentrazione della ricchezza è formulata senza attribuire una regia segreta o fare affermazioni non verificabili.

## Prima della pubblicazione
Il modulo è dimostrativo. Servono backend o servizio newsletter, privacy policy, cookie policy e verifica professionale delle proposte economiche e giuridiche.

## Simulatore economico

La pagina `simulatore.html` contiene la prima versione della dashboard interattiva.
Usa Chart.js tramite CDN e funziona su GitHub Pages senza server.
Il file Excel scaricabile è incluso nella stessa cartella.
